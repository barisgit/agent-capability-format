# @caplet/adapters

Target adapters that emit
[Agent Capability Format](https://github.com/barisgit/agent-capability-format) (ACF)
capabilities as native artifacts for Claude Code, Codex, Cursor, OpenCode, and Pi.
Importing the package registers every adapter; per-target entry points are
`@caplet/adapters/claude`, `/codex`, `/cursor`, `/opencode`, `/pi`, and shared helpers
live under `@caplet/adapters/common`.
